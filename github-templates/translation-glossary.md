# Translation glossary

The agreed terms of the product, per language. Copy this file to `.github/translation-glossary.md` of the product repository and replace the examples with your own terms. GitHub Copilot uses it in the review of pull requests (`.github/copilot-instructions.md`), and whoever translates (also with AI) uses it for the Excel file of `ZTR_TRANSL_REPORT`. The team changes it through pull requests; the reviewer of a translation decides with it.

The examples below are English and German.

## Terms that stay untranslated

Product names and product terms. In the other languages they are written exactly as in the source, and a translation that is the same as the source is correct.
