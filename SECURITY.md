# Security policy

## Supported versions

Only the latest state of the `master` branch is supported.

## Report a vulnerability

Please do not open a public issue for a security problem. Use the private reporting of GitHub: on the repository page choose **Security**, then **Report a vulnerability**. Describe what is affected and how to reproduce it, without real tokens, names of companies or customer data. You will get an answer as soon as a maintainer can read it.

What counts as a security problem in these tools: a way to read or use the GitHub token of another user, to send a token to a host other than github.com, to write a table or variant of the system without authorization, or to bypass the review of a request without the documented exceptions (`#NOREVIEW`, `ZTR_DISABLED`).

See also "Security notes" in the [README](README.md#security-notes).
